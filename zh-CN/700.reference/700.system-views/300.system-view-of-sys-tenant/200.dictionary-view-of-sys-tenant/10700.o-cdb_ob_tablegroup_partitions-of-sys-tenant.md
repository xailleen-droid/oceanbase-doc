# oceanbase.CDB_OB_TABLEGROUP_PARTITIONS

> 说明

由于 V4.2.0 及之后版本中，表组不再有分区的概念，该视图不再使用，用户可以查询该视图，但查询结果为空。
对于 V4.2.0 及之后版本，可通过视图 CDB_OB_TABLEGROUPS 查询表组信息。有关表组的更多详细介绍，参见 关于表组。

## 功能描述

系统租户下展示所有租户的分区表组的一级分区信息。

## 字段说明

|        字段名称        |      类型       | 是否可以为 NULL |                                                                     描述                                                                      |
|--------------------|---------------|------------|---------------------------|
| TENANT_ID          | bigint(20)    | NO         | 租户 ID                                                    |
| TABLEGROUP_NAME    | varchar(128)  | NO         | TABLEGROUP 名称                                            |
| COMPOSITE          | varchar(3)    | NO         | 分区的表组是否为二级分区，值为 `YES` 或 `NO`                             |
| PARTITION_NAME     | varchar(64)   | NO         | 分区的表组的一级分区名                                              |
| SUBPARTITION_COUNT | bigint(20)    | NO         | 该值为 `NULL`                  |
| HIGH_VALUE         | varchar(4096) | NO         | 该值为 `NULL`            |
| HIGH_VALUE_LENGTH  | bigint(20)    | NO         | 该值为 `NULL`                             |
| PARTITION_POSITION | bigint(20) unsigned | NO   | 该值为 `NULL`    |
