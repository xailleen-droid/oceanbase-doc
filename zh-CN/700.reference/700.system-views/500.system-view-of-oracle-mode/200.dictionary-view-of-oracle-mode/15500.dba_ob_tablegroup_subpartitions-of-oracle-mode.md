# DBA_OB_TABLEGROUP_SUBPARTITIONS

> 说明

由于 V4.2.0 及之后版本中，表组不再有分区的概念，该视图不再使用，用户可以查询该视图，但查询结果为空。
对于 V4.2.0 及之后版本，可通过视图 DBA_OB_TABLEGROUPS 查询表组信息。有关表组的更多详细介绍，参见 关于表组。

## 功能描述

展示分区的表组的二级分区信息。

## 字段说明


|         字段名称          |       类型       | 是否可以为 NULL |        描述        |
|-----------------------|----------------|------------|----------------------------------------------------------------------|
| TABLEGROUP_NAME       | VARCHAR2(128)  | NO         | TABLEGROUP 名称    |
| PARTITION_NAME        | VARCHAR2(64)   | NO         | 表组的二级分区对应的一级分区名  |
| SUBPARTITION_NAME     | VARCHAR2(64)   | NO         | 表组的二级分区名         |
| HIGH_VALUE            | VARCHAR2(4096) | NO         | 该值为 `NULL`                                                       |
| HIGH_VALUE_LENGTH     | NUMBER         | NO         | 该值为 `NULL`                                                                          |
| PARTITION_POSITION    | NUMBER         | NO         | 该值为 `NULL`      |
| SUBPARTITION_POSITION | NUMBER         | NO         | 该值为 `NULL`             |
