# GV$OB_SQL_AUDIT

> **说明**
>
> 该视图从 V4.0.0 版本开始引入。

## 功能描述

视图 `GV$OB_SQL_AUDIT` 用于展示所有 OBServer 节点上每一次 SQL 请求的来源、执行状态等统计信息。该视图是按照租户拆分的，除了系统租户，其他租户不能跨租户查询。
