# ALTER SYSTEM FLUSH CACHE

## 描述

删除缓存。

  > 说明
    对于 Oracle 租户，如果要清除租户下指定 SQL 或 Schema 的计划缓存，需要使用 DBMS_PLAN_CACHE 系统包。

## 语法

```sql
ALTER SYSTEM FLUSH {PLAN
                  | LIB } CACHE [GLOBAL]
```

## 参数解释

| 参数 | 描述 |
|---------|------|
| PLAN | 清空执行计划缓存 |
| LIB | 清空 Lib Cache |

## 示例

```sql
obclient> ALTER SYSTEM FLUSH PLAN CACHE GLOBAL;
```
