# ob_early_lock_release

> 说明
该变量从 V2.2.30 版本开始废弃。ELR 产品行为调整为受租户级别配置项 enable_early_lock_release 控制。

`ob_early_lock_release` 用于控制事务是否开启提前解锁（ELR）功能。

| **属性**  |                                                 **描述**                                                 |
|---------|--------------------------------------------------------------------------------------------------------|
| 参数类型    | bool                |
| 默认值     | 0                   |
| 取值范围    | <li> 0：不开启   <li> 1：开启    |
| 生效范围    | GLOBAL              |
| 是否参与序列化 | 是                   |
