# nls_sort

## 功能描述

`nls_sort` 用于查看字符串值的排序规则。

  > **说明**
>
> 该变量不支持修改。

## 属性说明

|  **属性**  |                                                   **描述**                                                   |
|----------|------------------------------------------------------------------------------------------------------------|
| 参数类型     | varchar                 |
| 默认值      | BINARY                  |
| 取值范围     | N/A                     |
| 生效范围     | <li> Global   <li> Session    |
| 是否可修改    | 否  |
