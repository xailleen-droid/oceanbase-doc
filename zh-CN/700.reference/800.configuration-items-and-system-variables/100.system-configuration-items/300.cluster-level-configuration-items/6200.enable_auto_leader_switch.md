# enable_auto_leader_switch

> **说明**
>
> 由于 V4.x 版本对系统架构进行了优化调整，自动切主由单日志流控制，不再需要进行负载均衡，该配置项从 V4.0.0 版本开始删除。

`enable_auto_leader_switch` 用于设置是否开启自动切主。

|      **属性**      |                     **描述**                |
|------------------|---------------------------------------------------------|
| 参数类型             | Bool                                                 |
| 默认值              | True                                                  |
| 取值范围             | </li><li> True   </li><li> False    |
| 是否重启 OBServer 节点生效 | 否                                               |
