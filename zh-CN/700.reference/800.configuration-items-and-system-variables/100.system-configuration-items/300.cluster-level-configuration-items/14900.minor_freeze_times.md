# minor_freeze_times


> 说明
由于 V4.x 对存储架构进行了升级，且该配置项与 major_compact_trigger 配置项的含义相同，该配置项从 V4.0.0 版本开始删除。
在 V4.x 版本中，只能使用租户级配置项 major_compact_trigger 来控制租户冻结多少次后触发合并。有关配置项 major_compact_trigger 的更多说明，参见 major_compact_trigger。

`minor_freeze_times` 用于设置多少次冻结触发一次合并。

|      **属性**      |    **描述**    |
|------------------|--------------|
| 参数类型             | Int           |
| 默认值              | 100          |
| 取值范围             | \[0, 65535\] |
| 是否重启 OBServer 节点生效 | 否            |

> 说明
  
   该配置项的取值为 0 时，表示无论冻结多少次都不会自动触发合并。 
   该配置项与 major_compact_trigger 配置项具有相同功能。
