# log_archive_checkpoint_interval

> 说明

由于 V4.x 版本对物理备份恢复功能进行了架构的优化调整，该配置项从 V4.0.0 版本开始删除。
在 V4.x 版本中，可通过配置项 archive_lag_target 来设置归档延迟时间。有关租户级配置项 archive_lag_target 的详细说明，请参见 archive_lag_target。

`log_archive_checkpoint_interval` 用于设置冷数据的日志归档检查点的时间间隔。

|      **属性**      |   **描述**   |
|------------------|------------|
| 参数类型             | Time       |
| 默认值              | 120s       |
| 取值范围             | \[5s, 1h\] |
| 是否重启 OBServer 节点生效 | 否          |
