# backup_zone

> 说明
由于 V4.x 版本对物理备份恢复功能进行了架构的优化调整，该配置项从 V4.0.0 版本开始删除。
在 V4.x 版本中，暂不支持指定 Zone 进行备份。

`backup_zone`用于用户指定执行备份的 Zone。

|      **属性**      | **描述** |
|------------------|--------|
| 参数类型             | String  |
| 默认值              | 空字符串   |
| 取值范围             | 不涉及    |
| 是否重启 OBServer 节点生效 | 否      |
