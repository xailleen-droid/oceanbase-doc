# backup_dest_option

> 说明

由于 V4.x 版本对物理备份恢复功能进行了架构的优化调整，该配置项从 V4.0.0 版本开始删除。
V4.x 版本中，该配置项中各参数对应的功能表现如下：
有关日志归档延迟的时间间隔，可通过租户级配置项 archive_lag_target 来设置。
不再支持通过配置项来设置备份数据可恢复的时间窗口，系统租户和用户租户可通过 SQL 语句 ALTER SYSTEM ADD DELETE BACKUP POLICY 中的 RECOVERY_WINDOW 选项来进行设置。
仅支持自动清理备份，暂不支持手动清理清理功能，有关自动清理备份的相关操作，请参见 自动清理过期备份。
有关 Piece 的切换周期，可通过 SQL 语句ALTER SYSTEM SET LOG_ARCHIVE_DEST 来设置。
不再支持备份数据的备份（二次备份）功能，故不再支持指定备份集的冗余度。

`backup_dest_option` 用于控制备份相关的参数。

|        属性        |  描述   |
|------------------|-------|
| 参数类型             | String |
| 默认值              | 空字符串  |
| 取值范围             | 不涉及   |
| 是否重启 OBServer 节点生效 | 否     |
