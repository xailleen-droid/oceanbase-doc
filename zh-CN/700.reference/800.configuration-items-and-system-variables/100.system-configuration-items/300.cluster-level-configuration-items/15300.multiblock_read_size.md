# multiblock_read_size

> **说明**
>
> 由于 V4.x 版本进行了存储架构的变更，该配置项已不再适用，从 V4.0.0 版本开始删除。

`multiblock_read_size` 用于设置读取数据时 IO 聚合大小。

|      **属性**      |   **描述**   |
|------------------|------------|
| 参数类型             | Capacity         |
| 默认值              | 128k       |
| 取值范围             | \[0K, 2M\] |
| 是否重启 OBServer 节点生效 | 否          |
