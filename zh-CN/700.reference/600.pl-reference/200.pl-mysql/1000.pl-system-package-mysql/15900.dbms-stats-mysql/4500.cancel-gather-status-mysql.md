# CANCEL_GATHER_STATS

`CANCEL_GATHER_STATS` 用于取消统计信息收集命令。

## 语法

```sql
DBMS_STATS.cancel_gather_stats (
      taskid         VARCHAR2
    );
```

## 参数解释

|    参数    |        解释         |
|----------|-----------------------|
|taskid|表示正在收集任务的 ID。> 说明您可以通过查询 GV$OB_OPT_STAT_GATHER_MONITOR 视图获取taskid，更多关于该视图的介绍请参考 GV\$OB_OPT_STAT_GATHER_MONITOR。|

## 示例

```sql
obclient> CALL DBMS_STATS.CANCEL_GATHER_STATS(taskid);
```

> 说明
  其中 taskid 需要替换为实际值。
