# HELP

用于发送 `HELP` 命令，获取帮助信息。

> **功能适用性**
>
> 该内容仅适用于 OceanBase 数据库 Oracle 模式。

## 语法

```sql
UTL_SMTP.HELP (
   c         IN OUT NOCOPY   connection,
   command   IN              VARCHAR2 DEFAULT NULL)
RETURN replies;
```

## 参数解释

| **参数** |         **解释**         |
|--------|------------------------|
|c|SMTP 连接。|
|command|获取帮助消息的命令。|

## 返回值

| **返回值** |          **描述**          |
|---------|--------------------------|
|reply|command 的回复。如果有多个回复，则返回最后一个回复。|
